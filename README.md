![Version Badge](https://img.shields.io/badge/Version-0.1-brightgreen?style=for-the-badge)

## Introduction

This project investigates the recent dynamic changes in human oral microbiome ecology and evolution revealed by ancient metagenomics.

This repository contains the scripts and files used to generate the figures for this manuscript. The respository is organized as follows:

`00-documentation` - contains input and metadata files for the samples.

`01-resources` - contains files that are unchangeable resources for the analyses of this project.

`02-scripts` - additional scripts used for generating supplemental figures.

`05-results` - contains results tables and files that are used for plotting.

`06-publication` - contains scripts to produce the main text figures and the extended data figures, in their respective folders.
