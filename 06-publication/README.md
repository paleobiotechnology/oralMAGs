**Scripts to produce main text figures.**


`main_figures` - This folder contains the R markdown files with all scripts to produce the 5 main text figures. Each figure file is labeled with the figure number. There are two exceptions: `Figure 1` and `Figure 4`. For each of these figures, there are two files in the folder that are needed to produce all the figure panels. 

-For Figure 1, `world_map.R` is needed to produce the map panel. 

-For `Figure 4`, `Figure_4_archaea.Rmd` is needed to produce the archaea trees (panels F and G). 

`extended_data_figures` - This folder contains the R markdown files with all scripts to produce the 10 Extended Data Figures. Each figure file is labeled with the figure numbers. There is one exception: `Extended Data Figure 9` is produced with a python script.
