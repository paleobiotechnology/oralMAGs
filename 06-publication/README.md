**Scripts to produce main text figures.**


`main_figures` - This folder contains the R markdown files with all scripts to produce the 5 main text figures. Each figure file is labeled with the figure number. There are three exceptions: `Figure 1`, `Figure 2` and `Figure 4`.  

- For `Figure 1`: `world_map.R` is needed to produce the map panel. This is in the `main_figures` folder.

- For `Figure 2` panel B: the figure was generated by uploading the phylogenetic tree file to the Interactive Tree of Life website: https://itol.embl.de/ . The resulting figure was exported as a pdf. See the "Tree of life" section of `Figure_2.Rmd`. 

- For `Figure 4`: `Figure_4_archaea.Rmd` is needed to produce the archaea trees (panels F and G). This is in the `main_figures` folder.

`extended_data_figures` - This folder contains the R markdown files with all scripts to produce the 10 Extended Data Figures. Each figure file is labeled with the figure numbers. There is one exception: `Extended Data Figure 9` is produced with a python script.
