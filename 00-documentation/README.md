## Overview of the folder `00-documentation`

This folder contains documentation and metadata tables for samples and MAGs in this project, including summary tables produced by the analysis workflows. 

These files are used for generating figures from scripts in `06-publication/main_figures` and `06-publication/extended_data_figures`.

- `ASMB_MAGS_metaWRAP_postfiltering.tsv` - MAG refinement pipeline output table with summary statistics for ancient and modern calculus
- `CMC_assembly_MAG_automaticrefinement_summary.tsv` - MAG refinement pipeline output table with summary statistics for Cameroon plaque
- `ERSX_to_ERS_conversion_table.tsv` - Sample label conversion table
- `ancient_envt_bins_26_07_2024.tsv` - bins considered to be environmental contamination
- `ancient_envt_clusters_26_07_2024.tsv` - species clusters considered to be environmental contamination
- `class_gram_stains.tsv` - Gram stain of microbial taxonomic Classes
- `cluster_info_all_metadata_26_07_2024.tsv` - metadata for MAGs
- `cluster_taxonomy_for_taxdump_26_07_2024.tsv` - taxonomy input table for generating Kraken2 database
- `cluster_type_table_93.tsv` - Host information per 93% ANI species cluster
- `cluster_type_table.tsv` - Host information per 95% ANI species cluster
- `cmc_accession_codes_published.tsv` - Sample label conversion table
- `continent_coordinates.tsv` - coordinates for continents for plotting
- `csc001_taxonomy.tsv` - taxonomy for sample CSC001
- `csc_mags_info.tsv` - metadata for sample CSC001
- `ersx_code_conversion_table.tsv` - Sample label conversion table
- `gtdb_complete_anaerovoracaceae_genome_paths.tsv` - list of all Anaerovoracaceae genomes in GTDB
- `itol_homd_colors.txt` - colors used for coloring tree tips in ITOL
- `itol_nothomd_colors.txt` - colors used for coloring tree tips in ITOL
- `library_sample_eager_metadata.tsv` - sample metadata
- `mag_quality_table.tsv` - MAG quality estimates from checkM, checkM2, GUNC, etc
- `mag_sample_to_eager_label.tsv` - Sample label conversion table
- `mod_anc_refined_mag_taxonomy_26_07_2024.tsv` - taxonomy for all MAGs that passed quality thresholds
- `other_sample_codes.tsv` - additional code conversion table
- `poor_samples.tsv` - poorly preserved samples that were removed from analyses that used metagenomic taxonomic profiling
- `poor_samples_humans.tsv` - list of poorly preserved human samples that were removed from analyses that used metagenomic taxonomic profiling
- `qual_fail_or_non_oral_list_mag_source.tsv` - all MAGs that didn't pass quality checks
- `rgig7111_anaerovoracaceae_complete_metadata_09_2025.tsv` - metadata for for Anaerovoracaceae genomes
- `zhu2022_accessions.csv` - sample info for Zhu, et al. 2022 MAGs
